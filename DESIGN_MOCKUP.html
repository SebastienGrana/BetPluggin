Vision de Design

Principes fondamentaux

  • Arcade ManiaPlanet: Couleurs vives (vert + orange) sur fond sombre, style futuriste/commande in-game
  • Densité haute: Information-riche sans surcharge visuelle; layout compact optimisé pour écrans 1280x720
  • État-driven: Les couleurs et les badges reflètent l'état du marché (OPEN/WAITING/CLOSED)
  • Clarity-first: Pas d'effets flous, gradients, ou animations superflues; flat design crisp
  • Lisibilité monoespace: Typo monospace (Monaco/Courier) pour le caractère arcade et l'alignement des nombres

Cas d'usage

  • Joueur casual: Voit le widget HUD (pot, bets actifs), clique "Open Market", place un pari rapide
  • Hardcore betteur: Consulte le leaderboard pour étudier les stats, regarde les cotes en direct, place des bets stratégiques
  • Admin/Spectateur: Monitore les flux de Planets, vérifie la conformité des paiements, archive les stats

Typographie

  • Display/Monospace: Monaco, Courier New (arcade/futuriste)
  • Body/Labels: Système sans-serif (Roboto, Ubuntu, ou fallback system)
  • Utility/Données: Monospace avec font-variant-numeric: tabular-nums (align à droite)

Échelle typographique

  • Titres (Widget, Modal): 16-24px, bold, uppercase, letter-spacing 1-2px
  • Labels: 10-11px, uppercase, letter-spacing 0.5px, color #FF6B00
  • Données (Planets, cotes): 12-13px, monospace, tabular-nums, color #00FF00 ou #E0E0E6
  • Texte corps: 12-15px, sans-serif, line-height 1.6

Architecture UI

Layer 1: Widget HUD (Ultra-compact)

BetWidget extends WidgetView — petit panneau dans le coin haut-gauche, flanquant le Dedimania.

  • Positionnement: widget_x = -110, widget_y = 70, z_index = 130 (décalé gauche pour flanquer Dedimania)
  • Taille: size_x = 40, size_y = 8 (ultra-compact: 2-3 lignes seulement)
  • Contenu (2-3 lignes):
    • Ligne 1: Statut badge (OPEN/WAITING/CLOSED avec couleur) | Pot total | Nombre de bets
    • Ligne 2-3: Bouton "Open Market" cliquable pour accéder à la vue complète
  • Mise à jour: Refresh à chaque bet_placed, bet_resolved, language switch
  • Contrainte visuelle: Minimal footprint — affiche uniquement les infos essentielles; tous les détails (bets perso, odds, leaderboard) dans la Market View

Layer 2: Market View (Modal interactif)

BetMarketView extends ManualListView — liste cliquable avec colonnes et actions.

  • Colonnes:
    • Player (nickname, searchable, sortable)
    • Pot on them (somme des bets, non-sortable)
    • Odds (cotes pari-mutuelles en live, non-sortable)
  • Actions rapides: Boutons Bet 100 / 250 / 500 / 1000 pour chaque joueur
  • État: Si market_is_open, affiche "Betting is OPEN"; sinon "Betting is currently closed"
  • Flux: Clic joueur → clic montant → place_bet(player, target_login, amount) → toast confirmation/erreur

Layer 3: Leaderboard (Vue secondaire)

BetLeaderboardView extends ManualListView — classement all-time avec stats détaillées.

  • Colonnes: Nickname, Bets, Win %, Wagered, Net, Best Win, Streak
  • Tri: By default par Net (gain/perte), peut aussi trier par Win %
  • Couleurs sémantiques:
    • Net gain → vert #00CC66
    • Net loss → rouge #FF3333
    • Streak positive → vert, streak negative → rouge
  • Mise à jour: Après chaque résolution de bet (map/round end)

État du marché (State machine)

  • CLOSED → badge rouge, boutons désactivés, message "Betting is closed"
  • WAITING → badge jaune, boutons désactivés, message "Waiting for round start"
  • OPEN → badge vert, boutons actifs, affiche les cotes live

Recommandations d'Implémentation

1. Conversion XML templates

⚠️ Contrainte ManiaPlanet: Les widgets utilisent du XML (pas de HTML). Les tableaux PyPlanet deviennent des grilles de labels avec alignement positional.

Structure pour Market View (table en grid):

<frame id="market-list">
  <!-- En-têtes -->
  <label x="0" y="0" text="Player" style="..." />
  <label x="55" y="0" text="Pot on them" style="..." />
  <label x="85" y="0" text="Odds" style="..." />

  <!-- Lignes (répétées pour chaque joueur) -->
  <frame id="player-row-1" y="-15">
    <label text="{player.nickname}" x="0" />
    <label text="{pot}" x="55" />
    <label text="x{odds}" x="85" />
  </frame>
</frame>

2. Alignement et typography

  • Chiffres (Planets, cotes): Utiliser font-variant-numeric: tabular-nums en CSS pour aligner à droite dans les styles
  • Labels: UPPERCASE + letter-spacing pour le caractère arcade
  • Statut badge: Couleur dynamique selon app.market_is_open

3. Gestion de l'état (State-driven rendering)

Dans BetWidget.get_context_data():

if self.app.market_is_open:
    status = 'OPEN'
    status_color = '73FF51FF'  # Green hex
elif self.app.scope == Bet.SCOPE_ROUND and self.app.current_round_number is None:
    status = 'WAITING'
    status_color = 'FFCC00FF'  # Yellow hex
else:
    status = 'CLOSED'
    status_color = 'FF7B7BFF'  # Red hex

4. Couleurs en formatage ManiaPlanet

  • Vert accent: 73FF51FF (ou $0F0 shorthand)
  • Orange: FF9933FF (ou $F90 shorthand)
  • Rouge: FF3333FF (ou $F00 shorthand)
  • Gris neutre: E0E0E6FF (ou $FFF light)

5. Responsive design

  • Widget HUD: Reste compact; si >10 bets actifs, afficher "Multiple bets" avec short list
  • Market View: Full-width modal pour 1280x720; scrollable si >20 joueurs
  • Leaderboard: Affichable en portrait (scroll horizontal) ou landscape (full table)

6. Séquence d'actions (UX flow)

1. Joueur ouvre le widget HUD

Voit le statut du marché et ses bets actifs.

2. Clique "Open Market"

Modal Market View s'ouvre avec la liste des joueurs et cotes live.

3. Sélectionne un joueur et un montant

Ex: clic sur "XeNos", puis clic "500 Planets".

4. SendBill in-client

Le serveur envoie une facture au client du joueur pour confirmation.

5. Confirmation + toast

Si confirmé: "Bet placed: 500 on XeNos @ x2.8". Widget HUD se rafraîchit.

6. Résolution (map/round end)

Leaderboard se met à jour. Joueur voit ses stats et streaks.

API PyPlanet utilisées

  • WidgetView — widget persistant HUD
  • ManualListView — listes cliquables avec colonnes
  • self.manager.ui — gestion des modals/affichages
  • player.send_chat_message() — toast notifications (confirmation/erreur)
  • self.subscribe('open_market', ...) — event listeners

Considérations de performance

✓ À optimiser:
  • Cache les cotes pari-mutuelles (mises à jour seulement lors de nouveaux bets)
  • Pagination du leaderboard (afficher top 50, pas tout les 1000 joueurs)
  • Limiter les refreshes du widget à chaque bet (throttle à 500ms)

Notes Supplémentaires

Accessibilité

  • Contraste suffisant (vert #00FF00 sur fond sombre → WCAG AAA)
  • Pas de dépendance au couleur seule (utiliser également texte + icônes pour état)
  • Labels clairs et explicites (pas de jargon abbrevé)

Évolutivité future

  • Ajouter un onglet "My Bets History" (filtré par joueur)
  • Afficher les "trending bets" (les plus populaires en temps réel)
  • Notifications de mises à jour (quand les cotes changent de 10%+)
  • Export CSV du leaderboard (admin tools)

Langues & Localisation

  • Tous les strings en strings.properties (ou équivalent i18n)
  • Nombres en locale.format() (différencier virgule/point décimal)
  • Symboles monétaires: "Planets" plutôt que abréviation
